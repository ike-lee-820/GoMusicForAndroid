修复
- 上一版给「时间 → 明暗边界位置」加了果冻缓动，把逐字进度非线性化，字亮起的时刻与真实演唱时间对不上（时间不准确）；那层回弹又只作用在纵向切句，横向沿字流的渐亮反而被削弱。已完整删除该版全部改动：果冻缓动函数、当前行的缩放与位移回弹、graphicsLayer 变换，逐字边界回到严格线性，亮起时刻与演唱时间一一对应。
- 新版逐字歌词与老版行级歌词切到下一句时的跟随滚动依旧生硬：系统 animateScrollToItem 是固定 spring，每切一句先取消上一个动画、速度归零再弹出去，落到下一句一顿；两种歌词共用同一段跟随循环，所以都生硬。

新增
- 行间跟随改为 520ms 缓入缓出的连续推进：按目标行相对视口顶部的真实像素距离逐帧平滑滚动，起止速度都为 0，不回弹、不倒退；目标行不在可视区时仍退回系统动画，行为不变。
- 横向渐亮带从 3 个字宽略微放宽到 3.6 个，右偏 0.25 改为 0.20，暗 → 亮沿字流铺得更开、边界两侧都留过渡；仍然只有字形明暗两档，没有渐变条、光晕或任何叠加层。
- 首次进入直接落位、隔一句跳的修复、点击歌词跳转、手动滑后 4 秒抑制、上滑显示 / 下滑隐藏控制栏全部保持原样。
