# GoMusic 26.11.90

## ① 电台页：删 Banner、一次性加载、空板块隐藏、48 小时缓存

旧版是「每个接口一个『刷新』按钮，点一下才发一个请求」，进页面三十多个板块全是空的提示文字，Banner 还单独占一块。

- **删除 Banner**：`/dj/banner` 这条 feed 和解析键一起移除，不再渲染、不再请求
- **所有信息一起请求**：进电台页一次性把除「搜索」外的全部板块排进请求队列，6 路并发（避免一次打满 30 多个连接拖垮服务端）；`{uid}` 只取一次账号信息复用，不再每个板块各发一次 `/user/account`；谁先回来谁先显示
- **没有回应的隐藏这个板块**：接口返回空 / 失败的板块整块不渲染（标题、说明、分隔线一起消失），顶部给出「隐藏 N」入口，展开后可填参数、单独重取；不再为每个空板块弹一条红字错误
- **全量缓存 48 小时**：所有板块的完整结果（包括空结果，用来记住该隐藏谁）整份落盘并记时间戳；48 小时内再进电台页直接读缓存，**不发任何请求**，也不随页面重组重复加载；顶部显示缓存时间，另有「强制刷新」由用户主动重置 48 小时起点
- 改了参数点「应用参数并重取」只重取这一个板块，写回该项缓存但不动整体时间戳，其余板块继续吃缓存
- 板块默认展示前 8 条，可「展开全部 N 条」；缓存的仍是全量条目
- 「搜索电台」子页由关键词驱动，仍即时搜索、不参与预取与 48 小时缓存

## ② 三个弹层重做样式

上一版「选择歌手 / 制作人员 / 歌词」套的是整页 `GoSheet`——56dp 顶栏加全屏白底，像又开了一个设置页，和播放器完全脱节。现在统一换成**半透明遮罩 + 底部圆角卡片**：顶部小把手、标题与副标题、圆形关闭按钮、表面色分层卡片，和「更多」菜单是同一套视觉语言。

- **选择歌手**：每位歌手一张圆角卡，52dp 圆形头像、名字加粗、下方标「网易云歌手·已匹配 / 本地曲库 / 按名字查找」，右侧主色「进入 ›」；加载中是一条细进度条，头像没到也能点
- **制作人员**：字段与内容分栏（如「作词」灰字标签 + 右侧深色正文），逐行独立卡片；右侧内容仍是 `SelectionContainer`，**长按可单独选中复制**，底部一枚主色「复制全部」
- **歌词**：顶部歌曲信息小卡（封面 / 歌名 / 行数 / 已选行数 / 歌手，右侧一键全选或清空）；歌词行左侧主色竖条 + 淡主色底，选中行主色加粗；底部把四个动作排成两行胶囊（复制 / 分享文本 / 歌词卡片·应用外 / 歌词卡片·应用内），不再挤成一堆小字按钮
- 三个弹层的功能与 26.11.89 完全一致：多歌手选谁进谁、制作人员逐行复制、歌词长按多选与两种卡片分享

## 说明与限制
`mapi.myocd.de5.net` 在沙盒返回 403，电台各接口与缓存读写**未做实机联调**，以 CI 编译＋签名校验为准。48 小时指的是「自动不刷新」：强制刷新、改参数重取、隐藏板块重取都是用户主动触发，不受此限制；这些操作会更新缓存内容但不重置整体 48 小时起点。缓存按板块 key 存于应用私有偏好，卸载应用或清数据后自然失效。
