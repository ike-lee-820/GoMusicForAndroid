# GoMusic 26.11.95

## 彻底断绝与旧曲库源站的联系

26.11.61 只是把源站调用「停用」（方法体抛异常 / 返回空），代码里仍留着整套源站 API 客户端、源站快照数据、以及「本站曲库」的概念，播放 / 下载 / 录制 / 投屏遇到非网易云歌曲还会掉到那些空壳接口上。这一版把整层连根移除。

### ① 删掉源站 API 客户端

`Data.kt` 里 `Api` 对象原有的 `/api/songs`、`/api/song/:id`、`/api/lyric`、`/api/artists`、`/api/proxy/raw`、`audioUrl()`、`get()`、`detail()`、`lyrics()`、`songs()`、`artists()` 整组删除；连通性探测客户端、源站音质详情缓存、根相对 URL 解析器一并删除。

剩下的 `client / downloadClient / json / bytes() / fetch() / abs() / rank()` 只是与曲库无关的通用工具，对象从 `Api` 改名为 **`Http`**，全项目调用点同步更新（一起听 `ListenTogetherApi`、电台 `RadioApi` 未受影响）。`Song` 里源站专属的 `locked` 字段删除；`repoName / owner` 仅为兼容历史快照保留，不再对应任何在线仓库，也不会拿去拼请求。

### ② 所有调用点不再有「源站兜底」

- **播放**：已下载走本地文件，网易云歌走网易云取地址；其余条目直接明确报错「该歌曲没有在线音源：旧曲库源站已移除，请播放本地文件或用网易云搜索」，不再假装能解析
- **下载**：非网易云歌不再取在线详情 / 在线歌词；封面取本地、歌词读本地文件；没有在线音频时明确提示
- **录制**：可用音质只来自网易云接口与本地已下载文件，非网易云不再查「在线详情档位」；素材下载与歌词读取同理
- **投屏**：非网易云歌不再向任何在线接口取流，只能用播放器正在播的本地文件
- **歌词 / 翻译**：非网易云、非设备本地的歌只认已下载文件与本地歌词，不再发在线详情请求
- **分享**：链接统一指向网易云歌曲页

### ③ 曲库数据本身不再混进源站条目

曲库只由「网易云歌曲 + 设备本地音频 + 已下载文件 + 还原字符导入的歌单」组装。历史快照里既不是 `nm_` / `dev:`、也没有下载记录、又没被任何歌单引用的条目，都是旧源站 `/api/songs` 灌进来的，一律不再进曲库；播放历史记录仍保留，但点进去不会再拿一个没有音源的旧条目伪装成歌曲。启动时不存在任何源站探测请求。

### ④ 界面与文档

全部「本站 / 源站曲库」文案改为「本地」，并修正语义：

- 设置里「接入网易云曲库」关闭时：`不接入网易云，仅使用本地曲库（设备文件 / 已下载 / 导入歌单）`
- 连接状态卡片：`在线曲库：网易云；本地曲库已就绪` / `离线：仅本地文件与已下载内容`，按钮改为「重新载入本地曲库」
- 播放器音质页：非网易云歌曲提示「仅网易云歌曲支持多档位，本地文件按原文件播放」
- 登录页、离线下载提示、README 全部同步（README 不再写后端 `gomusic.myocd.de5.net`）

### 保留不变
网易云全部能力（cloudsearch 搜索、每日推荐、私信 / 动态 / 电台 / 一起听官方房间、歌单双向同步、封面上传）、应用内 WebView 固定 UA + cookie、设备本地音频、还原字符导入导出、已下载文件与离线播放、歌词三点动画与切歌定位。

## 说明与限制
`mapi.myocd.de5.net` 在沙盒返回 403，本次为纯代码层清理与编译验证，**未做实机联网验收**，以 CI 编译＋签名校验为准。旧快照里被过滤掉的源站条目不会再出现在曲库与搜索里；如果某个自建歌单引用了这类 ssid，该条目仍会保留（歌单引用优先），但依然没有在线音源，只有本地已下载文件可播。`nmOn` 开关关闭时应用只剩本地内容，这是预期行为而非故障。
