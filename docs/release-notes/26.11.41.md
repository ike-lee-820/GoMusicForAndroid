修复
- 一首歌播完自动跳到下一首后歌名和进度都变了，却不出声，必须手动点一次播放
- 音轨切换时部分手机会发一次短暂音频焦点丢失，播放器开着自动焦点管理就把 playWhenReady 关掉，切歌后没人把它打开
- 新音源解析停在 IDLE 或出错时，切过去也不会自己恢复播放
- 播放结束的自动续播写在状态回调里直接改状态，可能被播放器在回调末尾覆盖
- 手动点上一首 / 下一首只做了 seek，遇到暂停或播放结束状态不会接着播

新增
- 自动切歌（播放结束 / 单曲循环重播）后在服务层补一次播放，并延后一拍再兜一次，覆盖焦点事件晚到的情况
- 新音源停在 IDLE 或带错误时自动重新准备再播
- 用户主动暂停、来电暂停、录制页暂停一律不补播，不会被强行唤醒
- 播放结束的续播改到下一帧执行，避免被播放器状态更新覆盖
- 手动上一首 / 下一首切完后明确恢复播放
