修复
- 纵向切句滚动虽已改成连续推进，但末端完全无回弹，落位仍偏硬；果冻感应该只加在列表位移上，不能像 26.11.76 那样动到逐字时间轴。
- 横向逐字仍是「整字从暗到亮的亮度插值」（渐亮），做不到字内从左到右擦亮，例如「顺」字无法只亮丿、再亮川、最后全字。

新增
- 纵向：520ms 跟随滚动末端加约 6% 的轻微回弹（easeOutBack），起止速度仍为 0，落位轻轻弹一下。只改列表位移，逐字时间轴保持严格线性，字亮起的时刻依旧与真实演唱时间一一对应。
- 横向：逐字渲染改用双层字形绘制 —— 底层整字暗色，上层整字亮色按「该字被边界扫过的比例」裁掉右半。于是「顺」字先只亮左边的丿、再亮川、最后全字亮，是字内从左到右的滚动式擦亮，不再是整字渐亮。
- 折行：长句按实际测量字宽折成多行，每行独立从左到右擦亮；歌词字号 / 字体 / 字重设置、译文与罗马音、点击歌词跳转、亮暗两档颜色全部保留。
- 仍然只有字形本身的两档明暗，没有矩形、渐变条、光晕或任何叠加层，之前删掉的「棍子」不会回来。
- 首次进入直接落位、隔一句跳的修复、手动滑后 4 秒抑制、上滑显示 / 下滑隐藏控制栏、横屏手势全部保持原样。
