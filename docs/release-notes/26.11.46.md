修复
- 没有逐字时间轴的老歌词、本地歌词、离线歌词也会逐帧刷新、自动滚动到当前行并叠加整行扫光，与「高级歌词」表现一样
- 改版后的更多列表漏掉了音质与倍速入口，播放器内无法切换音质
- 点击更多列表里的功能项后卡片不收起，会盖在随后打开的设置、均衡器等页面上

新增
- 无逐字歌词的歌曲：歌词栏保持静止，不自动滚动、不逐帧刷新、不画扫光，只把当前行静态高亮；仍是大字样式，仍可上下滑动浏览与点击行跳转
- 逐字歌词保留原有的逐帧推进、自动跟随与字形扫光
- 更多列表新增「音质」「倍速」两项，点开后在卡片内切到子页；音质子页打开时才探测档位，置灰无音源档位、标记当前档，切换后立即按新音质重新准备播放
- 本站曲库进入音质子页时明确提示只有单一音源，不再是一个空列表
- 更多列表子页支持返回键与主菜单回退
