修复
- 歌词逐字高亮是一条光带画在文字背后，像一根棍子在后面滚，而不是光从字上面流过
- 扫光按「当前是哪个字」跳，跨字时会顿一下，没有整行连续流动感
- 未收藏时星标不够明确，播放器与更多列表各画各的，状态不一致
- 更多菜单是紧凑下拉框，与要求的歌曲信息头 + 图标行列表样式不符

新增
- 歌词扫光改为按整行进度从左到右连续推进，用字形合成把光只画在笔画上，折行与多语言混排都能连续流过，不再有背景光带
- 星标统一：未收藏为空心、收藏后为实心主色，封面页、歌词页、队列页、更多列表共用同一状态
- 更多列表改为半透明遮罩 + 底部圆角卡片：顶部显示封面、歌名、歌手、专辑，下方为主色图标与大字标签的操作行，可滚动
- 更多列表新增分享歌词、查看制作人员，原有分享、下载、加入歌单、MV、翻译、均衡器、3D 环绕、录制、已下载、历史、更新、设置与查看专辑/歌手全部保留
