# GoMusic 26.11.19 更新说明

- 版本：26.11.19（versionCode 121，可直接覆盖安装 26.11.18）
- 日期：2026-11-13
- 适用：Android 手机端；桌面端已停止开发
- 版本号按 `年.月.该月版本` 顺延。本文件同时作为 GitHub Release 正文与应用内「更新说明」全文。

## 一、新增：录制歌曲视频

横屏、竖屏的播放器功能栏都加了「录制视频」按钮，打开一个**独立整页**（不是叠在播放页上的弹层，避免误滑动）。页面上半部是「所见即所得」预览，下半部是全部选项，底部开始录制。

成品是 **MP4（H.264 视频 + 原音轨）**，画面采用横屏播放器样式：左侧歌曲信息区（专辑大图 / 标题 / 歌手 / 专辑），右侧居中歌词（当前句高亮、上下渐隐、可带译文），底部进度条与时间。预览和正式编码调用同一个 `renderRecFrame()`，改完参数立刻能在预览里看到。

### 可选项

| 项目 | 说明 |
| --- | --- |
| 比例 | 16:9 / 9:16 / 1:1 / 4:3 |
| 分辨率 | 短边 480 / 720 / 1080 / 1440p，自动算长边并对齐偶数 |
| 帧率 | 24 / 30 / 60 fps |
| 音质 | standard → sky 共 10 档；优先用已下载的同档位文件，没有才按档位取地址 |
| 歌词字号 | 12–48 sp，按输出高度归一化 |
| 歌曲信息区大小 | 18%–60% 宽度占比，封面与文字区一起变 |
| 歌词全体快进 / 延迟 | −5000 ~ +5000 ms，100 ms 步进；正数整体提前 |
| 更改歌词 | 直接粘贴整篇 LRC 顶替原歌词；「重置为原歌词」一键还原 |
| 歌词字体 | 导入 ttf / otf（存到应用私有目录），或清除回系统字体 |
| 是否开启翻译 | 开启时把译文一并录进画面，关闭只录原句 |
| 人声 | 原声 / 减弱人声；减弱时强度 0–100% 连续可调，100% 约等于伴奏 |
| 码率 | 4 / 8 / 12 / 16 Mbps |

预览区可以 −5s / +5s 拨动位置、一键「回到当前」，用来检查歌词时间轴与偏移是否对得上。

### 音乐直接原样打包

「原声」模式下，音轨由 `MediaExtractor` 读出**压缩样本原封不动**写进 `MediaMuxer`：不解码、不重编码、不经过任何 DSP，音质与源文件逐字节一致。只有选了「减弱人声」才会解码成 PCM → 处理 → AAC 重编码（这一步必然要重编码，无法原样打包）。

## 二、无 AI 人声减弱

不依赖训练数据或深度学习模型，纯信号处理：把左右声道拆成 mid / side，按强度衰减居中的人声、保留两侧伴奏，再对 mid 做一次低通把 150Hz 以下的鼓与贝斯补回来，避免声音发薄。强度拉到 100% 时接近伴奏。

按随附的《无 AI 伴奏提取技术方案》，`app/src/main/cpp/` 里同时放了 NDK 版本的 REPET-lite 实现（STFT 2048 / hop 512 / 时域中值重复背景模型 / 软掩码 / 重叠相加）与 `CMakeLists.txt`。**默认不参与构建**——CI 环境不保证带 NDK，直接挂上会让整包编译失败；按该目录 README 取消 `externalNativeBuild` 注释即可切换成原生内核，接口与 Kotlin 版一致。

## 三、后台与通知

录制跑在 `RecorderService` 前台服务里（`dataSync` 类型），退到后台、熄屏都会继续；通知栏持续显示「已录制 N%」，带「取消」操作。完成后写入系统「影片 / GoMusic」（Android 10+ 走 MediaStore，旧版本写应用私有影片目录），并弹完成通知。逐帧按真实帧率 pacing，保证 Surface 时间戳与音轨时间轴对齐；因此录一整首歌需要接近歌曲本身时长。

## 四、其余功能均未改动

26.11.18 的更新页面排版、26.11.17 的歌词免登录快速通道与点「暂无歌词」重试、竖屏 3D 环绕入口与面板留白、26.11.16 的更新文案截断修复与 Markdown 排版，以及自动续播、音质逐档回退、均衡器、封面高清、验证码登录风控提示、代理 v6.gh-proxy 等全部保持原样。

## 五、验证

1. 横屏展开控制栏第一行、竖屏功能行都出现「录制视频」图标，点开是整页而非弹层
2. 改比例 / 字号 / 信息区 / 偏移，预览立刻跟着变；导入字体后歌词字形改变
3. 粘一段 LRC 后预览换成新歌词，「重置为原歌词」恢复
4. 选「原声」开始录制 → 通知显示进度 → 退到后台仍继续 → 完成通知提示保存到 影片/GoMusic
5. 选「减弱人声」并把强度拉到 100%，成品人声明显减弱、低频不空
6. 设置 → 关于显示 `26.11.19`；检查更新 → 查看更新说明可看到本文全文

## 六、限制（如实说明）

- 无法做实机听感与画面验收，编码链路以代码与 CI 构建结果为准；首次在真机录制时建议先用短歌试一遍
- 「减弱人声」是纯信号处理的**近似伴奏**，不承诺录音室级分离；自由爵士、复杂古典等重复结构弱的曲目效果有限
- 录制为实时 pacing，不能比歌曲本身更快；取消后已产出的临时文件会清理
- 原生 2DFT / Adaptive REPET 的自适应周期与 NEON 矢量化尚未启用，当前 REPET-lite 为固定周期
