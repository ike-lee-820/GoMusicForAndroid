修复
- 字内擦亮的亮 / 暗之间是一条硬裁切边，明暗一刀切、过渡太突兀；暗档 alpha 0.28 与亮档 1.0 反差也偏大。
- 切句翻动时歌词是纯平移，没有任何轻微形变，显得死板。

新增
- 字内擦亮边界改成软过渡带：边界两侧各留 14% 字宽、分 10 档，从亮平滑到暗；同一份字形按互不重叠的横向区间分段绘制，因此仍是字形本身的颜色，没有叠加层、渐变条、光晕或背景矩形。过渡带在字两端会自动收窄到 0，p 刚过 0 不会突然冒出一整条亮带、快到 1 也不会留一条暗尾。
- 暗档从 alpha 0.28 提到 0.32，减小整体反差；实测过渡段最大相邻亮度跳变约 0.15，不再一刀切。「顺」先只亮丿、再亮川、最后全字的字内滚动式擦亮完整保留，逐字时间轴仍严格线性。
- 翻动扭动：切句跟随滚动期间，当前行叠一次极轻的扭动（rotationZ 1.3° 内 + 1.4% 挤压，起止归零、只来回一下）；非激活行不订阅这个逐帧状态、不变形。只动行的位移形变，不碰逐字时间轴，字亮起的时刻依旧与演唱时间一一对应。
- 26.11.78 的纵向果冻回弹、字内从左到右擦亮，以及首次进入直接落位、隔一句跳的修复、点击歌词跳转、手动滑后 4 秒抑制、上滑显示 / 下滑隐藏控制栏、横屏手势全部保持原样。
