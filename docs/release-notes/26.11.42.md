修复
- 逐字歌词接口只给 yrc 不给 lrc 时，歌词列表会显示「暂无歌词」
- 预取只提前取下一首的播放地址，且与播放解析共用连接池，切歌时仍会互相抢线程
- 新歌词接口请求失败、返回异常或内容为空时没有退回老歌词接口，歌词直接为空

新增
- 设置 → 外观：亮色 / 暗色 / 自动三档，亮色下状态栏图标同步变深
- 逐字歌词数据层：支持 yrc 逐字、中文译文、罗马音与制作信息，多语言轨按 600 毫秒容差对齐
- 新歌词接口失败一律退回老歌词接口，再退本地歌词；点「暂无歌词」重试走同一条链
- 「我的喜欢」本地集合与搜索记录持久化，未登录也能用
- 一次性聚合搜索：一次输入同时搜歌手、专辑、歌曲，结果按相关性混合
- 独立预取调度域：提前取后两首的播放地址、歌词与歌曲详情，切歌取消旧任务，不抢播放线程
