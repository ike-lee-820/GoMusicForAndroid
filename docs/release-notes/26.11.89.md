# GoMusic 26.11.89

## ① 多歌手不再串到第一个：新增「选择歌手」弹窗

根因：播放器里 `陈奕迅/王菲` 这类合唱歌手名，旧逻辑按 `/` 拆开后只取**第一个搜索命中**去开歌手页，于是界面显示的是合唱歌手名、进去却是陈奕迅的页，另一位完全点不到。

现在点**封面页歌手文字**、信息区菜单「查看歌手」、更多菜单「查看歌手」，以及专辑/歌曲详情页的歌手文字，统一进「选择歌手」弹窗：

- 按 `/ , & 、 ; | \` 拆分并去重，名字**立即列出（0 等待，不挂在网络请求后面）**
- 后台并发按每个名字搜 `/search?type=100`，补上**歌手头像与真实 id**，谁先回谁先填
- 选谁进谁：有真实 id 进网易云歌手页，没搜到的仍可按名字进本地歌手页
- 设备本地音频按既有约定不跳页、不联网
- 已有真实 `nmArtistId` 的单歌手也走弹窗（只有一项，列表即刻可点）；收起播放器放到真正选中之后，不再提前关页

## ② 「查看制作人员」改成弹窗，可长按复制

以前点这一项是直接把制作信息丢进系统分享面板，看不到完整内容。现在弹出「制作人员」卡片：逐行展示作词/作曲/编曲/监制等，每行 `SelectionContainer` **长按即可单独选中复制**，底部另有「复制全部」。没有制作信息时明确显示「暂无制作人员信息」。

## ③ 「分享歌词」改成「歌词」整页

更多菜单里的「分享歌词…」换成「**歌词**」，打开后展示**全部正文歌词**（过滤 yrc 开头的 JSON 制作信息行），不再只弹一次系统分享：

- **长按任意一行选中**，选中行高亮；可继续点选多行，也能「全选 / 清空选择」；一行都没选时默认为全部歌词
- 底部对选中内容四个动作：**复制**（剪贴板）、**分享**（系统文本分享）、**制作歌词卡片 → 应用外分享**、**制作歌词卡片 → 应用内分享**
- 歌词卡片用 Canvas 画成 1080×1440 深蓝渐变 PNG（歌名 / 歌手 / 选中歌词 / 落款），存到私有 `cache/share`，经 FileProvider 以 `image/png` 交给系统分享；超过 6 张自动清理旧卡片
- 应用内分享走私信：网易云私信没有图片接口，因此把卡片排版成文本（歌名 + 选中歌词 + 落款）发到选中的会话/好友，并自动关掉歌词页让选人弹层露出

## ④ 应用内分享可以浏览所有好友

之前「分享到私信」只列 `msg/private` 的**最近会话**，没有会话就几乎选不到人。现在弹层顶部多出「最近会话 / 所有好友」切换：

- 好友来自 `/user/follows`（关注）分页拉取，关注翻完自动续 `/user/followeds`（粉丝），合并去重
- 每页 30 位，底部显示「已加载 N 位」与「加载更多」，加载中有进度条
- 支持按**昵称 / 签名本地搜索**，列表带头像、昵称、签名；点任意好友直接发送
- 未登录或接口返回空时给出明确提示，不再静默空白；「发给指定 uid」直填仍保留
- 歌词卡片的应用内分享也复用这个选人弹层

## 说明与限制
这轮附带的 50 个链接资源解析请求全部失败，接口参数按你此前贴在正文里的文档实现；`mapi.myocd.de5.net` 在沙盒返回 403，**未做实机联调**，以 CI 编译＋签名校验为准。好友列表依赖 `/user/follows` 与 `/user/followeds` 对当前账号可用，私信发图片受网易云接口限制所以应用内分享发的是文本卡片；歌手头像依赖搜索接口返回 `picUrl`，个别歌手可能没有头像。
