# GoMusic 26.11.14 更新说明

- 版本：26.11.14（versionCode 116，可直接覆盖安装）
- 日期：2026-11-13
- 适用：Android 手机端；桌面端已停止开发
- 版本号按你指定的 `年.月.该月版本` 使用 26.11.14。仓库里 26.11.10 / 11 / 13 从未发布，本版为跳号，特此说明。

---

## 一、Release 文案 = 完整更新说明（已落地）

`release.yml` 发布时读取该版本的完整说明作为 Release 正文：

- 优先 `docs/release-notes/<版本号>.md`，缺失时回退根目录 `RELEASE_NOTES.md`
- 两者都没有则**构建直接失败**，不会再发出「自动构建的正式版 APK」那句占位文案
- Release 已存在时用 `gh release edit --notes-file` 同步正文，重跑也会刷新

也就是说，你现在看到的这个 Release 页面正文，就是这份文件全文。

## 二、应用内可以完整查看更新文档

之前应用里看不全，卡在两处：`Updater.parseInfo()` 把 `body` 截到 600 字；弹窗里说明区又限制在 260dp 高。

本版改成：

- **不截断**：Release 正文全文进入 `Info.notes`
- **双保险**：弹窗打开后后台再拉一次仓库归档的 `docs/release-notes/<版本>.md` 原文（先走 v6.gh-proxy.com，失败回退直连），正文被清空或代理只给摘要时仍能拿到未删减的 md
- **整页可滚**：说明区占满剩余高度、内部滚动，长文档能从头读到尾
- **长按复制**：`SelectionContainer` +「复制全文」按钮，底部显示「共 N 字」
- **随时可看**：设置页「检查更新」区域新增「更新说明」按钮，不要求有新版本；此时只显示文档与「关闭」，不会出现下载按钮

启动时检测到新版本自动弹出的更新页用的是同一套。

## 三、3D 环绕（新增，独立于均衡器）

- 控制栏第一行新增自绘环绕图标，沿用 MV / 均衡器的 24dp 网格与笔触；开启时用主题主色
- 点开是环绕设置弹层：开关 + 强度（弱 / 中 / 强），设置持久化，重启保留
- DSP 是**独立链路**：解码 → 均衡器 → 3D 环绕 → 输出，不使用任何频段增益，均衡器全关也生效；FFmpegKMP / MediaCodec 两条内核都覆盖
- 实现为交叉馈送 + 对侧耳 ITD（约 0.25ms）+ 质数抽头早期反射；150Hz 以下不空间化，输出软限幅防止叠加削波
- 默认关闭，不与均衡器的「深夜聆听」等响度补偿叠加

## 四、横屏展开控制栏不自动下一首（服务层兜底）

自动续播原先只依赖界面侧的播放器监听，播放页重组（横屏展开两行控制栏）时容易丢掉结束事件。

本版在 `PlaybackService` 的 `Player.Listener.onPlaybackStateChanged` 里加了服务层兜底：播放器停在 `STATE_ENDED`、队列里还有下一首、且不是单曲循环时，主动 `seekToNext()` 并继续播放。服务层与界面状态解耦，控制栏展开 / 收起、横竖屏切换都不会把它带 dispose。

## 五、本版**没有**包含的内容（如实说明）

1. 「均衡器和设置改成单独全屏页面防止误滑动」**本版未做**：两者仍是原来的弹层（EqSheet / SettingsSheet）。这项改动涉及大范围路由改造，留到下一版。
2. FFmpeg 原生 AAR 仍未内置：内核保持可插拔，未带 .so 时由 MediaCodec 接管，功能不变。
3. 历史 Release 的正文只回填了 26.11.12 与本版；更早版本仍是旧的占位文案（仓库里的归档 md 是完整的）。

## 七、风险与限制

- 3D 环绕用通用头部模型，不是个性化 HRTF；不同耳机可能听出声像偏后，可用强度三档校准
- 服务层兜底只在「队列里确实还有下一首」时生效；单曲循环、队列仅一首按原逻辑不跳
- 我无法做实机听感与手势验收，以上以代码与 CI 构建为准
